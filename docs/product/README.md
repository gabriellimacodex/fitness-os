# Product Documentation

Formal Fitness OS product documentation will live in this directory. Epic 00 records only the constitutional principles and engineering context already approved; it does not define or implement additional product behavior.

The current web foundation is PWA-ready. This term does not claim a service worker, offline caching, a production icon matrix, or a complete install experience. Those capabilities require future explicit scope.

See the repository-level `PRODUCT_PRINCIPLES.md` for the current source of product constraints.
