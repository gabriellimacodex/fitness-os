# Movement content reviews

Published movement versions bind durable, privacy-minimized review files here:

`docs/execution/content-reviews/movements/<movementId>-v<contentVersion>.md`

This directory is empty on purpose. The shipped catalog has no published
entries. Gate A content publication remains blocked by
`HUMAN_PERCEPTION_REQUIRED` until a Human Review Authority issues both role
receipts for an exact source commit and digest.

Do not add a production signing key, reviewer identity, or legal content to
this repository. Synthetic test keys cannot satisfy publication.
